# Code de conduite

Rustcraft Manager suit l'esprit du [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

- Sois respectueux et bienveillant, avec tout le monde, quel que soit son niveau, son origine, son
  genre ou son identité.
- Critique le code et les idées, jamais les personnes.
- Pas de harcèlement, d'insulte, de propos discriminatoire ni de publication d'informations
  privées d'autrui.

Un comportement inacceptable peut être signalé en privé aux mainteneurs du dépôt. Les mainteneurs
peuvent retirer un contenu, et exclure temporairement ou définitivement une personne du projet.
